> 확인된 이용 조건을 먼저 적어 두는 자리다.

## 1. 범위

이번 파일럿은 **문서 1건**만 쓴다. 후보 B(사전규격공개)와 C(작성 가이드)는 이번 단계에서 제외한다.
문서 집합이 바뀌면 `corpus_version`을 올린다.

```yaml
corpus_version: rfp-demo-v1
documents: 1
status: not_acquired      # not_acquired → acquired → extracted → labeled
```

## 3. 확인된 이용 조건

**확인한 것만 적는다. 공공누리 표시가 없다는 사실만으로 추정하지 않는다.**

NIA 저작권정책 페이지([운영정책 > 저작권정책](https://www.nia.or.kr/site/nia_kor/06/10603000000002016092303.jsp),
2026-09-06 확인)에 다음 문장이 있다.

> "한국지능정보사회진흥원에서 제공하는 모든 자료는 저작권법에 의하여 보호받는 저작물로서
> 별도의 표시 또는 출처를 명시한 경우를 제외하고는 원칙적으로 한국지능정보사회진흥원에
> 저작권이 있으며 이를 무단 복제, 배포하는 경우에는 저작권법 제97조의5에 의한
> 저작재산권침해죄에 해당함을 유념하시기 바랍니다."

> "개인 또는 법인이 한국지능정보사회진흥원의 컨텐츠를 링크하거나 인용, 복제 및 재배포 등을
> 통하여 사용하실 때와 … 수익을 얻거나 이에 상응하는 혜택을 누리고자 하는 경우에는
> 한국지능정보사회진흥원과 사전에 협의를 하고 허락을 얻고 출처가 한국지능정보사회진흥원임을
> 밝혀야 하며 …"

여기서 **확정할 수 있는 것**

- 자료의 저작권은 원칙적으로 NIA에 있다고 기관이 명시했다
- 복제·재배포에 대해 **사전 협의와 허락, 출처 표시**를 요구한다고 명시했다
- 공고 페이지와 첨부파일 목록은 로그인 없이 열람된다 (2026-09-06 확인)

**확정할 수 없는 것 — 확인 필요**

- 위 두 번째 문장이 *모든 이용*에 걸리는지, *수익 목적 이용*에 한정되는지 문장 구조상 단정할 수 없다
- 비상업적 연구·평가 목적의 로컬 사용이 협의 대상인지
- 추출 텍스트의 일부(짧은 인용)를 공개 평가셋에 담는 범위
- 공고 종료 후에도 첨부파일 URL이 유지되는지

같은 페이지에 **"세부화면(서브도메인)으로 링크시키거나 페이지를 프레임 안에 넣는 것은
허용되지 않습니다"** 라는 문장도 있다. 그래서 이 문서에서는 공고 상세 URL을 인용하되,
**외부 공개물에서 인용할 때는 게시판 목록 또는 기관 첫 화면을 함께 표기**한다.

## 4. 이용 조건이 명확해지기 전까지의 취급

- 원본 파일과 **전체 추출 텍스트를 Git에 커밋하지 않는다.** `data/raw/`·`data/extracted/`는 `.gitignore`에 있다
- 공개 평가셋에는 **긴 원문을 복제하지 않는다.** 좌표(`char_start`/`char_end`)와
  판정에 필요한 최소 메타데이터만 저장한다
- 결과 문서에 원문을 인용해야 하면 **판정에 필요한 최소 길이**로 줄이고 출처를 표시한다
- 저장소에 남기는 것은 이 문서의 표(URL·취득일·파일명·SHA-256·상태)뿐이다

## 5. 취득 절차 (사용자 작업)

첨부파일 다운로드는 `curl`로 요청하면 **HTTP 403**이 돌아온다(2026-09-06 확인).
브라우저로 직접 받아야 한다.

1. 공고 페이지를 연다
   `https://www.nia.or.kr/site/nia_kor/ex/bbs/View.do?cbIdx=78336&bcIdx=29940&parentSeq=29940`
2. 첨부파일 목록에서 **`1._제안요청서(최종)_조달청.hwpx`** 를 내려받는다
   (직접 링크: `https://www.nia.or.kr/common/board/Download.do?bcIdx=29940&cbIdx=78336&fileNo=2`)
3. 저장 위치 — 저장소 루트 기준
   ```
   data/raw/doc-001.hwpx
   ```
4. 해시를 기록한다
   ```bash
   shasum -a 256 data/raw/doc-001.hwpx
   ```
5. 위 §2 표의 `취득일` · `document_sha256` · `페이지 수` · `문서 상태`를 채운다

**받기 전까지 추출·청킹·평가셋 작성은 시작하지 않는다.**
